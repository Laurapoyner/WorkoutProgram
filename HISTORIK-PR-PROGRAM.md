# Historik pr. træningsprogram

Denne version ændrer historiksiden til tre niveauer:

1. **Standardvisning – programmer**
   - Ét kort pr. træningsprogram.
   - Programmerne sorteres efter senest udførte pas.
   - Kortet viser antal registrerede pas, antal fuldførte og seneste dato.

2. **Programdetalje**
   - Klik på et program for at se alle gange netop dette program er udført.
   - Grafen vises kun for det valgte program.
   - Grafen tilpasser sig data:
     - LSI-programmer: LSI % pr. test.
     - Styrkeprogrammer: højeste registrerede belastning i kg pr. øvelse.
     - Score/tidsprogrammer: gennemsnitlig score pr. øvelse, når enhederne kan sammenlignes.
     - Ellers: gennemførelsesprocent over tid.
   - De enkelte pas vises med seneste først og kan foldes ud.

3. **Se alle træningspas**
   - Samlet kronologisk liste over alle registrerede pas.
   - Seneste pas vises først.
   - Der kan søges på program, dato og øvelse.

Visningen er samtidig forenklet til mobil, så standardhistorikken ikke starter med en stor graf eller tabel.
