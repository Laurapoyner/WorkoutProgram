# Mobil + LSI-opdatering

Denne version indeholder:

- samlet LSI-udviklingsgraf på Historik med alle LSI-tests og alle testdatoer
- 90 % referencelinje i grafen
- scorebaserede øvelser viser deres faktiske resultater (hop, cm, reps, fejl) i stedet for 0 kg
- LSI vises direkte sammen med resultaterne
- historikken starter automatisk i kortvisning på mobil
- mere kompakte historik- og træningskort på små skærme
- kladde-banneret er gjort mindre og har ingen blink/pulse-animation
- programvælgeren er begrænset i bredde på mobil

Cloudflare/MongoDB-opsætningen er uændret.
