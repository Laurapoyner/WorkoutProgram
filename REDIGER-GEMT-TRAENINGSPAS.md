# Rediger gemte træningspas

Et allerede gemt træningspas kan nu redigeres fra Historik via **Rediger pas**.

Du kan rette:
- dato
- varighed
- note til hele passet
- sæt, gentagelser og belastning
- venstre/højre værdier
- score/testresultater og LSI
- noter på den enkelte øvelse
- begrundelsen for øvelser markeret som "Ikke udført"

Passet beholder samme ID, så der bliver ikke oprettet en dublet. Historikdata og grafer opdateres sammen med passet i MongoDB.
